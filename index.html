Link Install Mandiri 100% Offline (Tanpa Perlu Hotspot Lagi)
https://... Buka Link HTTPS Sekarang
Buka link HTTPS di atas 1 kali saja di Chrome HP, lalu pilih Tambahkan ke Layar Utama / Install app. Setelah terpasang, aplikasi bisa dibuka kapan saja tanpa Hotspot & tanpa internet!
Alamat Koneksi HP (Ketik di Chrome HP Anda)
http://10.34.144.42:3000
Pastikan HP dan Laptop terhubung ke Wi-Fi atau Hotspot HP yang sama.
1. Sambungkan Wi-Fi / Hotspot: Hubungkan HP Android dan laptop ini ke jaringan Wi-Fi yang sama (atau nyalakan Hotspot di HP lalu sambungkan laptop ke Hotspot HP).
2. Buka di Chrome HP: Buka aplikasi Google Chrome di HP Anda, lalu ketik alamat http://10.34.144.42:3000 di bagian atas.
3. Pasang seperti Aplikasi Biasa: Di HP Anda, tekan tombol "Install app" atau tekan menu Titik Tiga (⋮) di pojok kanan atas Chrome › pilih "Tambahkan ke Layar Utama" (Add to Home screen / Install app).
4. Siap Dibawa ke Kebun / Gudang (Offline Field Mode): Tekan tombol "Sync Data ke Memori HP" di bawah ini dari HP Anda sebelum berangkat ke kebun agar HP tetap bisa mencatat barang masuk/keluar walaupun jauh dari laptop!
